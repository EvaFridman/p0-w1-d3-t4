# p0-w1-d3-t4 · Раскрывающийся FAQ без скриптов

> Тип: research (на лекции не давали — ищешь сама) · Репозиторий: один отдельный

## Контекст

Блок «частые вопросы», где ответы раскрываются по клику, обычно делают на JS. Но в HTML есть
нативный раскрывающийся элемент, который работает с клавиатуры и доступен из коробки — без
единой строки скрипта. На лекции его не было: находишь сама.

```
<details>
  <summary> Вопрос ▸ </summary>   ← Enter/Space
     ответ раскрывается                 без JS
</details>

ищешь сама: details/summary, aria-expanded,
доступность раскрывающихся блоков
```

## Что нужно сделать

Сделать FAQ из нескольких вопросов, где ответ раскрывается/сворачивается нативно, доступно с
клавиатуры и понятно скринридеру. JS не использовать (на неделе 1 его ещё нет). Разобраться,
какой элемент HTML это умеет и как он связан с доступностью.

## Релизы

### Release 1 — нативное раскрытие
Найти и применить `<details>`/`<summary>` для одного вопроса-ответа. Проверить, что
открывается мышкой и с клавиатуры (Enter/Space на заголовке). В `A11Y.md` — как это работает.

### Release 2 — список вопросов
Собрать FAQ из 4–5 пунктов. Подумать, какой должен быть один открыт по умолчанию (атрибут
`open`). Пройти весь блок Tab’ом.

### Release 3 — доступность
Раскопать, как скринридер сообщает состояние раскрыто/свёрнуто и причём тут `aria-expanded`
(делает ли `<details>` это сам?). Записать вывод в `A11Y.md`.

## Критерии приёмки

* FAQ раскрывается и сворачивается без JS, работает с клавиатуры.
* Состояние раскрытия доступно скринридеру.
* В `A11Y.md` своими словами объяснено, как `<details>`/`<summary>` обеспечивают доступность и
  нужен ли тут `aria-expanded` вручную.
